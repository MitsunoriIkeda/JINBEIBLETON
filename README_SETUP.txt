========================================================================
JINBEIBLETON - Setup Guide & Manual
========================================================================

【日本語 (Japanese)】
JINBEIBLETONをご利用いただきありがとうございます！
本アプリがAbleton Liveと通信し、AIでコントロールするためには、
以下のセットアップが必要です。

■ ステップ 1: Remote Script のインストール
1. このフォルダの中にある「install_remote_script.command」を
   ダブルクリックして実行してください。
2. ターミナル画面が開き、「✅ AbletonJS Remote Script installed successfully!」
   と表示されればインストール成功です。

■ ステップ 2: Ableton Live の設定
1. Ableton Live を起動（または再起動）してください。
2. 設定画面を開きます（Mac: Cmd + , ）。
3. 左側のタブから「Link, Tempo & MIDI」を選択します。
4. 「Control Surface（コントロールサーフェス）」の空いている行の
   ドロップダウンメニューから「AbletonJS」を選択してください。
   ※ Input / Output は「なし」のままで問題ありません。
5. 設定画面を閉じます。

■ ステップ 3: JINBEIBLETON の起動
1. 「JINBEIBLETON.app」を、Macの「アプリケーション (Applications)」フォルダに
   ドラッグ＆ドロップしてコピーしてください。
2. コピーしたアプリケーションフォルダ内の「JINBEIBLETON.app」を起動します。
   （※ 初回起動時は「開発元が未確認のため開けません」という警告が出ることが
   あります。その場合は、システム設定 > プライバシーとセキュリティ > セキュリティ
   から「このまま開く」を選択してください）
3. 自動的にAbleton Liveと接続され、アプリ画面の右上に
   「✅ Ableton Connected」と表示されれば準備完了です！
4. 画面中央下部の「START」ボタンの左側にある「緑色の自動車アイコン」
   （設定ボタン）をクリックし、ご自身の Gemini API Key などを
   入力してご利用ください。


========================================================================
【English】
Welcome to JINBEIBLETON! 
To allow the AI to control Ableton Live, you need to set up the 
MIDI Remote Script by following these steps:

■ Step 1: Install Remote Script
1. Double-click the "install_remote_script.command" file included 
   in this folder.
2. A terminal window will open. If it says 
   "✅ AbletonJS Remote Script installed successfully!", you are good to go.

■ Step 2: Configure Ableton Live
1. Open (or restart) Ableton Live.
2. Open Settings / Preferences (Mac: Cmd + ,).
3. Go to the "Link, Tempo & MIDI" tab.
4. In an empty row under "Control Surface", select "AbletonJS" 
   from the dropdown menu.
   * Note: Leave Input / Output as "None".
5. Close the Settings window.

■ Step 3: Launch JINBEIBLETON
1. Drag and drop the "JINBEIBLETON.app" into your Mac's 
   "Applications" folder.
2. Launch the app from the Applications folder.
   (Note: On the first launch, macOS might warn you about an 
   unidentified developer. Go to System Settings > Privacy & Security 
   and click "Open Anyway".)
3. It will automatically connect to Ableton Live. Once you see 
   "✅ Ableton Connected" in the top right of the app, you are ready!
4. Click the "Green Car Icon" (Settings) located to the left of the 
   START button to enter your Gemini API Key and other configurations.
